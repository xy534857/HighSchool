# 青禾高中：校园前端与 E2E

卡顿、课堂持续性与 situation 修复见 [campus-repair.md](campus-repair.md)。

入口为 `dist/index.html`；旧家庭版本保留在 `dist/family.html`。本版把独立的模拟基座接入可玩的校园前端，没有接回旧家庭剧情执行器。

## 可以玩什么

- 9 个场景：教室、办公室、卫生间、社团活动室、操场、中庭、图书馆、食堂、医务室。
- 1 个玩家角色、7 个独立 Soar NPC；54 件物品、53 种 tuning 交互。
- 点选场景人物、物品或地面。区域导航切换镜头；“前往”会让人物沿通路步行。
- 课桌学习、电脑查资料、看书、公告、洗手、独立厕位、吃饭、喝水、画海报、吉他、篮球、花坛、储物柜、床上休息，以及物品拿取、借用和归还。
- 5 项行动队列、取消、1×/3×/8× 时间、暂停、七种需要、随身物品、个人见闻。
- 邀请与独立加入、发言轮次、多轮问答、多人邀请、学习小组；借阅要经过对方同意，交接会改变物品持有者。
- IndexedDB 保存、读取完整原生记忆、当前会话、剩余行动和玩家队列。
- 设置中可导出角色的实时规则请求，载入生成的规则回复。默认无外部模型调用。

## 模块边界

| 层 | 文件 | 责任 |
|---|---|---|
| 内容 | `dist/content/school-*.json` | 物品类型、实例、房间、交互、需要、作息和初始个人规则 |
| 内容生成 | `scripts/author-school-content.py` | 从基础 tuning 及社团内容包整理校园内容；运行时加载纯 JSON |
| 模拟 | `dist/foundation/` | 世界事实、个人感知、原生 Soar、物品效果、交互协调、存档 |
| 前端适配 | `dist/campus/service.js` | 将合法能力映射为菜单，玩家命令排队，输出只读展示快照 |
| 后台线程 | `worker.js`、`bridge.js` | 请求关联、顺序推进、将 Soar 计算移出绘制线程 |
| 渲染 | `scene.js`、`models.js`、`geometry.js` | 用房间和物品类型的视觉字段构建场景，跟随真实坐标及姿态 |
| 兼容渲染 | `software-renderer.js` | 无 WebGL 时在 Canvas 中绘制同一 Three 场景图的简化几何 |
| 界面 | `app.js`、`style.css`、`storage.js` | 点选、菜单、队列、对话、记录、视角、存读档 |

执行器没有校园角色或特定物品 ID 的条件分支。新增已有模型类型的物品，以及组合现有效果的交互，继续只改 tuning。新视觉模型注册在 `modelFactories`；新底层能力需要基座原语。图片不是交互热点的固定背景，人物与物品的位置来自模拟。

## 本轮修复

- 每次候选计算复用一次个人感知快照，避免每个行动重复读取全部记忆。
- 根据家具 footprint 与房间 bounds 进行网格寻路，交互占用点单独定义。
- 候选阶段排除占用的座位与已知不足的资源，完成阶段仍再次检查。
- 远处资源未知时显示抵达后确认，不伪造“资源不足”。
- 接近移动对象时按仍可感知的位置有限重规划。
- 模拟时钟使用独立计时，避免兼容渲染的帧率拖慢游戏时间。
- 菜单内容不变时保持原按钮节点，避免点击期间重建。
- 原生规则接口自动纳入 tuning 新增的需要字段。

## 验证

```bash
npm test
```

16 项基座与校园集成测试通过。校园测试覆盖 9 区连通、所有物品交互点可达，9 类跨区域行动的实际效果，以及原生角色的多轮回答、同意借阅、交接和存档恢复。

浏览器 E2E 使用实际页面按钮、后台 worker、原生 Soar WASM 和界面回写，未用测试接口直接修改游戏状态。已记录 15 项通过检查：9 个区域、学习完成、多轮对话与借出、跨区域行走、洗手效果、保存读取、归还履约。证据见 `research/campus/browser-e2e.json`、`integration.json`。

本次云浏览器禁用 WebGL，因此端到端测试使用 Canvas 兼容渲染。WebGL 主路径使用同一场景和交互代码，但没有在这次云浏览器中完成 GPU 渲染验收。记录中保留了这个边界。

## 当前范围

这是校园交互与模拟前端；不声称已经完成开放式自然语言聊天、完整人格建模、动态日终导演或高质量长期剧情验收。当前台词来自有语义效果的 tuning，初始个人规则是预先编写后由 Soar 执行。运行时新规则仍通过现有请求/校验/安装接口进入，默认不会访问付费 API。

地图使用房间通路与家具矩形轮廓；尚没有多人避让、门扇碰撞与精细肢体接触。Canvas 兼容模式降低了几何细分和绘制频率；WebGL 模式保留圆润模型，默认关闭动态阴影以降低开销。资源是实际有限值，不会因换镜头恢复。
