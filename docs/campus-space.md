# 校园空间、设施占用与动作

本次修复面向交互表现、人物和家具重叠、厕所共用，以及无法理解区域连接的问题。学校认知仍使用独立 Soar agents；动作、碰撞和视图均读取 tuning，不由剧情脚本决定走位。

## 数据与模块

- `dist/content/school-tuning.json`：类型的 `colliders` 是局部矩形阻挡；`slots` 包含位置、朝向、侧面/正面入口、坐卧姿势和可选的隐私属性。行动通过 `animation.clip` 选动作，通过 `motion.loop` 声明实际运动路线。
- `dist/content/school-scene.json`：九个房间的地图位置、双向连接、出入口、装饰阻挡与物品坐标。食堂重新布置桌距，人物出生位置避开家具。
- `dist/foundation/space.js`：带角色尺寸的寻路、逐段碰撞检查、近邻避让和交谈站位。角色接近别人时留出距离和对方离开座位的通道。
- `dist/foundation/execution.js`：预约设施 → 走到入口 → 就位 → 执行动作 → 退出 → 释放预约。取消或被对话打断时也必须先退出。相向行走按任务开始时间和稳定次序让路、重新寻路。紧急需求遇到设施全满时，由候选 utility 提高等待优先级，经 Soar 选择；不会转去执行长时间普通任务。
- `dist/campus/animation.js` / `models.js`：带肘、膝的程序化模型和动作。写画、打字、吃喝、洗手、弹琴、投篮、教学、翻看、递物、坐卧等使用不同的关节姿势和道具。入座和离座有姿势过渡，跑步实际改变位置。
- `dist/campus/map.js`：全校总览共用真实房间与物品布局，显示角色、出入口和实际寻路结果；可以选区域查看或安排前往。
- `dist/campus/spatial-upgrade.js`：升级旧存档的空间描述与正在使用的设施，同时保留个人认知、运行时规则和已发生的事件。

课堂准备可在原位转为上课；持续课程分段记录进度，保持座位预约，到下课才退出。相应能力通过 `transition`、`repeatUntilPeriodEnd` 配置。

厕所为独立单人隔间。预约、使用和退出期间都保留占用；使用时关门并隐藏隔间内人物，不能被拉进谈话。界面显示可用数量和设施状态。空间判定以圆形人物与矩形家具近似，不使用动画网格做物理碰撞。

## 验证

`npm test` 覆盖基座、原生认知、生活流程和空间回归。新增检查包括：

1. 动作映射、坐卧关节和各类活动的不同道具/姿势。
2. 厕所独占、隐私、取消后退出、再次使用；床上休息锚点。
3. 相向通行保持间距，跑步沿可通行的路线移动。
4. 8 个自主角色共享 3 个厕所，全部完成且不重复占用。
5. 带使用中任务的旧存档升级后保留记忆并可正常退出设施。

结果记录在 `research/campus/spatial.json`；地图、设施和动画的浏览器检查单独记录。测试不会调用外部模型。

动作仍是卡通程序动画：没有手指级 IK、布料模拟或完整面部表情。跨房间仍通过有位置的出入口切换，总览显示这些区域与通道；没有新增可自由行走的走廊场景。

Canvas 兼容模式缓存 48 个裁剪后的深度层，变换缓存用数值指纹避免逐帧大量格式化；帧节流统一在场景入口。它仍不等同于 WebGL 深度缓冲。
