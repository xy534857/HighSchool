# 校园通行、持续计划与人格核查

## 对旧实现的结论

扩充前多数角色只有兴趣动作偏好、公共作息和 situation 的短任务。`coping` 全部是 `verify`，`sensitivity` 只有很小差异。Soar 的个人记忆和目标执行机制存在，但这不等于已经实现完整的人格模型。仅列出下一步和一句选择理由，不能展示长期自主性。

## 本次实现

校园现在有 19 个区域。教学楼走廊连接东西公共走廊；西侧分别进入办公室、医务室、无障碍卫生间，东侧分别进入音乐教室、社团工坊、活动中心。`room.transit:false` 的室内功能房间不能作为其他目的地的中间通道。中庭、操场和公共走廊承担中转。地图、门口和实际路径读取同一份连接数据。它仍是分区地图，房间间切换，不是整个校园的无缝连续网格。

`cognition`、`projects` 是新的 tuning 扩展段；同样可由 `extendContent` 注册。角色的 `profile.projects` 指向目标配方。八名角色各有周目标，包括画作、社团展示、乐谱与乐器练习、篮球、跑步、学习资料、备课。目标优先级低于正常课程、午餐与紧急需求，个人练习按窗口和间隔推进。

配方生成目标时只解析对象和参数绑定，保留表达式供运行时求值。目标定义、阶段、上次主步骤完成时间存入各自的原生 Soar SMem；JS 只缓存查询结果和索引。资源、库存、空间和执行过程仍由模拟基座管理。

一个阶段可包含：

- `repeatUntil`：真实结果达到条件才完成阶段。
- `skipWhen`：其他实际行动已经达成条件，则跳过该阶段。
- `alternatives`：原方法不可执行时，提出采购、补充等前置方法。
- `spacingMinutes`：两次主要练习之间的间隔；补充材料不会被误记成一次练习。
- `activeWhen`（目标层）：可投入该目标的时段。
- `motive`、`label`、`blockedReason`：作者或模型在定义时提供的解释，不是事后生成的心理旁白。

这些方法作为 Soar 的候选操作参与选择，目标不会直接强制播放动作队列。同一目标的设施选择考虑区域距离；同一动作可服务多个目标时，采用优先级较高的目标绑定。实际完成事件才更新阶段。存读档恢复原来的目标和累积进度。

`人物与计划` 显示所有角色的真实目标、动机、全部步骤、累计值、时间窗口和暂停/受阻状态。它是显式观察界面，读取其他人物的计划不会把那些知识传递给玩家角色。查询计划不会推进目标状态。

## 人格现在影响什么

每个人仍然共享认知架构，而有独立的 SMem/EpMem、规则和状态；不是八套完全不同的程序。

| 定义 | 实际用途 |
|---|---|
| 社交主动性 | Soar 的主动搭话条件和优先级 |
| 目标坚持 | 生成该角色个人目标的优先级 |
| 情绪敏感 | 原生 Soar 对真实失约的情绪强度计算 |
| 应对方式 | 原生情绪记录中的 coping，以及依据这条记忆提出的交谈、求证、退开或找人倾诉操作 |
| 兴趣/角色职责 | 个人项目配方、作息和既有规则 |
| 个人经历 | 只接收自己观察或听到的事件，不能从全局日志获得未知事件 |

规则接口支持声明的 `profile-*` 字段，以及个人记忆的 `value/emotion/coping/intensity` 条件；`matchTarget` 把社交操作对象绑定到记忆当事人。未知原因仍保持不确定，不把拒绝自动等同于恶意。当前情绪强度由原生 `mind-read` 根据时间衰减，以五个游戏分钟为查询缓存粒度；原来的失约事实继续保留。忙于私密交互、只有拒绝邀请可执行时，也有低优先级回应规则，避免没有操作提案而持续产生 impasse。

## 验证范围

`tests/campus/planning.test.mjs` 使用实际 Soar WASM：361 组区域路径与所有设施交互入口；运行时安装计划，执行查资料、跨日、课程打断、读档、继续查资料并打印；缺纸时采购、补充再画画；相同失约在不同人上得到不同情绪强度和操作，未收到事件的人没有该记忆。运行时计划补丁由开发阶段编写，走与模型回复相同的验证/安装接口，没有调用外部 API。

浏览器检查计划面板、人物切换、地图路径和独立入口。基线回归另外覆盖上课与缺勤、午餐、多人会话、situation 合作/拒绝、资源链、占位与读档。

最终完整回归结果：34 项通过、0 项失败，包含新增的 4 项规划/人格验证。记录见 `research/campus/planning-test-run.txt`、`planning.json`、`planning-browser.json`。

## 尚未达到的原始目标

这次的长期规划属于可中断、可继续、按结果推进的目标与方法执行。它不包含通用目标分解搜索，不会自行发明注册能力之外的新行为。周目标和人格配方是预定义内容；模型可以通过现有接口新增规则与目标，但没有开启每日自动反思、自动改写人格、世界规则或下一天情节。

复杂社会动机（喜欢一个人同时害怕同伴排斥、长期猜忌、解释改变后的关系修复等）还需要更丰富的关系规则与情境验证。本次不能据此宣称已完整满足最初“家有儿女”式可解释的长期社会自主性。对照测试证明的是特定机制，而不是所有角色在所有生活情境里都像真人。
