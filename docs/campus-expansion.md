# 校园扩充与物品规则

本版将学校扩为 17 个区域、148 件场景物品、40 类物品和 84 个注册交互（包含隐藏的调度、回复和等候行为）。其中新增 7 个动作姿态：显微观察、实验、清洁、写生、钢琴、乒乓练球、拉伸。

## 空间与访问

教学楼走廊连接教室、图书馆、实验室、办公室、音乐教室和中庭。办公室连接医务室与无障碍卫生间；中庭连接男女卫生间、美术工坊和操场。南侧有食堂、体育馆、种植园；工坊连接学生活动中心。

每个区域有独立 bounds、地图位置、出入口、地面功能区和家具布局。前端地板、墙体、相机范围、地图和路径规划读取同一份数据。所有 153 个使用位置的 approach 均可达。地图代表区域连接和相对位置，并不是无缝连续楼层。

男女卫生间各有三个独立隔间、三个洗手池和垃圾桶，另有通用的无障碍卫生间。`room.access.when` 同时约束候选、寻路和手动命令；UI 显示拒绝原因。个人柜的 owner 约束使用者。原有资源租约继续覆盖前往、使用和离开全过程。

## 可组合规则

内容入口：`scripts/expand-school-campus.py`。`python scripts/author-school-content.py` 会依次重建基础内容、行为包、空间包、扩充包；输出仍是 `dist/content/school-*.json`。

| 声明 | 执行职责 |
| --- | --- |
| `types.tags / slots / colliders` | 按语义绑定设施，预约使用位置，处理导航 |
| `types.state / visible / inspect` | 有类型的持久物品状态与角色感知范围 |
| `types.decay` | 指定数值随游戏时间变化及上下限 |
| `types.service` | 指定每天何时由后勤补给/整理哪些状态 |
| `actions.requirements` | 可解释的使用条件，例如余额、已领餐食、所有者 |
| `actions.requires` | 抵达和执行完成时核验的物品材料条件 |
| `actions.effects` | 原子执行库存、个人资源、需求与事件变化 |
| `resources` | 个人计数资源的名称、初值、范围和每日补贴 |
| `routines` | 根据时段、兴趣和已感知状态生成本地行动优先级 |

例如：领取午餐消耗 6 元和一份食堂库存，获得一份随身餐食；吃饭必须已经领餐，消耗餐食并产生待归还餐盘；归还清除个人餐盘，增加回收台计数。自主 Soar 可以连续选择这三个交互。已用餐具也显示在个人状态中。

其他链条包括研究→打印（消耗纸墨和余额）、购买文具→补画纸→画画→展出、观察/实验→清洁器材、种植照护→成熟→采收。厕纸、洗手液、样本、画布、点心等有限，次日指定时间补给。补给是明确的后勤服务规则，没有伪装成未出现的清洁员行动。

`environment.js`、`effects.js`、`affordances.js` 不包含学校物品或人物 ID。扩展包可声明新的资源类型，并组合已有效果原语。新执行机制或新动作姿态仍需明确扩展引擎/渲染器。

## Soar 与生成规则

个人资源会作为 `resource-<id>` 数值进入原生 Soar 的输入帧，也列在模型契约中。运行时回复仍经过类型、内容版本、经历引用和原生解析校验。

扩充测试生成并实际安装了一条“音乐熟练低于 10 时练钢琴”的规则，验证它改变选择，并在数值达到门槛后不再选中。使用的是助手编写的规则回复，没有调用外部 LLM API，也没有宣称验证外部模型生成质量。

较大的学校暴露了原有会合规则的缺陷：早到者完成走路任务后会先去做别的事。扩充包加入“已经答应并到场时等候同伴”的可覆盖本地偏好，同时给跨区会合留出更长时间。上课、紧急需求和新决定仍可打断等候。

## 存档与界面

`campus-upgrade.js` 为旧学校存档补充区域、物品、资源与规则，保留原生记忆、人物政策、余额和运行时自定义内容。已有物品迁移至新布局，更新 approach 和地图知识；旧版正在吃饭的任务补足其已持有餐食。

右侧有设施检索与分类交互，显示库存、占用、归属、补给时间和失败条件。随身物品窗口显示校园卡、餐食、餐盘、资料、文具和个人技能积累。

## 验证边界

自动测试覆盖全部路径、关键资源链、权限、原生 Soar 生成规则接入、自主用餐、课堂与会合、占位与碰撞、对话和旧存档迁移。浏览器另行验证地图、设施菜单、空间画面和实际操作。

设施库存和个人积累是离散计数；乒乓球是单人回弹练习。尚未加入完整课程表轮换、实验教师监督、全校财务平衡或多人体育比赛。Canvas 兼容渲染保留近似深度排序，不能据逻辑测试声称所有视角绝无视觉遮挡问题。

最终验收：30 项自动测试全部通过。浏览器实际走通了男女入口限制、暂停时的入口禁用、女生厕位使用、显微观察后的样本消耗、清洁后复用，以及个人研究积累显示。记录和画面位于 `research/campus/expansion-*`。
