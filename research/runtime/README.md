# 本轮实际运行记录

`live-social-report.json` 来自真实 Soar WASM 的人工接管运行，约 14 分钟现实时间，从第 1 天 17:21 跑到第 4 天 21:41，共 9,162 个半分钟模拟步骤。3 个角色参与实验，其余角色设为离场；8 个 agent 仍创建。外部模型调用 0。

12 个实际请求中，10 份由 Codex 根据收到的个人上下文作答并成功安装；2 份因操作者超过实验的 180 秒截止而超时，迟到回复没有安装。请求/回复编号不是剧情节点。初始事件通过实际多人会话注入一次，此后不指定行动和结果。

## 时间与性能

- 实验成功请求的人工等待约 **15.0–108.3 秒**；其中包含操作者阅读、推理、编写和工具操作。
- 校验/安装约 **4.8–153.3 ms**。
- 半分钟世界推进 p50 **0.72 ms**，p95 **181.59 ms**，最大 **374.78 ms**。大量正在执行活动的步骤不重新决策，因此 p50 很低。这是 3 人实验、8 个已加载 agent 的进程测量，不是 8 人全活动场景的帧率。
- 浏览器独立检查中，Canvas 兼容渲染观察到 **25 fps**、位置更新约 **172 ms**。渲染在主线程，Soar 和模拟在 Worker。不同硬件需重测。
- 这次长跑未实际进入脚本的压缩夜晚/读档分支，`saveRestored=false`。读档恢复与过期响应由单独的真实 WASM 回归测试验证，不把这次长跑算作读档验证。

## 调试发现与修复

1. 找人或开会话的前置方法曾误推进“说出界限”步骤；现只允许主动作完成该步骤。
2. 日终普通事件过多挤掉关键社交事件；现优先保留相关社交见闻。
3. 原生记忆曾将直接听见的接受当作与 pending 冲突的传闻；现用明确的交互结果类别更新，等待步骤可正常结束。
4. 为限流新增的轮转决策曾延误课程切换和回应；紧急安排可超过普通预算。
5. 复核未完成的关系目标时，曾怀疑距离惩罚过大；逐步轨迹确认他们确实在找人，尚未遇上合适交流机会。额外回归验证远处的人际目标仍能驱动真实跨区域行走，没有通过增大优先级强推结果。

`debug-attempt-1/` 保留第一次失败观察；编号 07/08 文件是超时的请求和迟到回复。主报告和各记录均保留真实状态，不要求所有角色按预定剧情和好。

## 复现方式与范围

`npm test` 是无人值守的真实内核、校园和本地 HTTP 回归。`npm run test:live` 则必须有人逐次回答 `.runtime-lab/` 中的请求。重新运行时清理/另存旧的该目录，避免旧文件被误当作新回复；正式服务使用 UUID 作业文件名避免冲突。

这证明了当前注册能力内的关系计划、有限人格调整、异步安装和基础生活的衔接。没有测量 DeepSeek 的真实生成质量、费用和延迟，也没有证明长达数月的任意事件都能自动得到合理策略。
